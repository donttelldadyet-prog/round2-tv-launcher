Connect to GitHub

The themes live in the Round2 GitHub project. This computer needs a key to change them. You only do this once per computer.

  1. Open GitHub › New fine-grained token (signed in as the Round2 account).
  2. Token name: Round2 themes – this computer. Expiration: 1 year.
  3. Repository access: Only select repositories › round2-tv-launcher and round2sg-home (the second one lets the Food menu tab publish).
  4. Permissions › Repository permissions › Contents: Read and write. Leave everything else as it is.
  5. Press Generate token, copy it, and paste it here.

The key is saved only in this browser on this computer. Anyone with it can change the TV themes, so don't share it in group chats. Delete it any time from the same GitHub page.

TV app updates

Newest Round2 Home: checking…

TVs look for new versions by themselves every few hours. When one is found, UPDATE READY shows next to Options › Staff, and staff install it from Options › Staff (PIN) › Staff tools › Update app, then Install. TVs on Android 12 or newer install by themselves while switched off.

Guests and backgrounds

How it works

  1. New theme: give it a name, add the video (paste a link from OpenArt, or upload a file up to 45 MB), choose rooms and dates.
  2. Switch automatically makes it the room's background on its own while the dates are live, and puts the normal background back afterwards. Turn it off to only add it to the TV's Background list.
  3. Sounds: upload your own ambience (rain on a window, café chatter, spooky wind) in the Sounds tab. It appears on the TVs under Options › Ambience, and a theme can play it while it's live.
  4. Info card position moves the description box so the logo in your video stays visible.
  5. Fit the video: drag the picture in the preview, or use the sliders, to zoom and move it. GitHub renders it that way for the TVs, so small fixes don't need a new video (or OpenArt credits). Any video works, even a portrait phone video: press Show whole video.
  6. Save & publish. GitHub prepares the video for TVs (about 2–4 minutes). TVs check every few hours and whenever someone goes back to the home screen (at most every 30 minutes), and download videos up to 2 weeks before the start date.
  7. To make one TV check right now: on the PC, .\round2tv.ps1 themes.

Moving a TV to another room

On the TV: Options › Staff (PIN) › Staff tools › This TV's room and pick the room. The character, colours, apps and themes all follow the room.

Install as an app

Windows (Edge or Chrome): the install icon at the right of the address bar. Mac (Safari): File › Add to Dock. Chrome on Mac: ⋮ › Cast, save and share › Install page as app.

If a TV is stuck

How to get past the Round2 menu to the TV's own screens: for staff settings, or if the menu freezes or keeps closing. Try the steps in order.

Android TVs: Kai (TCL), Kaeden and Maximillion (Sony), Atlas (Prism+)

  1. Hold Home for 2 seconds. The TV's own Android home screen opens and the Round2 menu stays out of the way for 5 minutes. Hold it again for another 5 minutes. A short press of Home brings Round2 back. If holding does nothing (some TCL TVs don't pass the long press on), go to step 3.
  2. Wait a few seconds. It fixes itself: a frozen menu reloads by itself, and a crashed app is reopened. If it crashes 4 times in a minute, it steps aside and leaves the TV on the Android home screen for 10 minutes.
  3. The master switch. Press the Settings button on the remote › Device Preferences (TCL: System) › Accessibility › Round2 Home button › Off. The TV behaves like a normal TV until you switch it back on. Round2 never switches it back on by itself.
  4. Prism+ (Atlas): its Settings menu hides the Round2 Home button helper, so switch it in Round2 instead: Options › Staff (PIN) › Staff tools › Home button › TV HOME (OK or ◀ ▶). Hold Home for 2 seconds for the TV's own home screen for 5 minutes. From the laptop: round2tv.ps1 rescue.
  5. From the PC, when the remote can't get past the menu: run .\round2tv.ps1 connect kai (use that TV's room name), then .\round2tv.ps1 rescue. It closes Round2 Home, switches the Home helper off and shows the Android home screen. When it's fixed: .\round2tv.ps1 homeguard turns the helper back on.
  6. Last resort: unplug the TV for 30 seconds and plug it back in. If the menu keeps crashing after that, step 2 lets you through within a minute.

Rooted LG TVs (with Homebrew Channel and LG Input Hook)

  1. Press Home 3 times quickly (each press within about 1.5 seconds). LG's own home screen opens. This works even if the Round2 menu is frozen, because the button is caught outside the menu. One press of Home goes back to Round2.
  2. Back on the remote leaves Netflix, an HDMI input or another app and returns to Round2.
  3. Staff switches: in Round2, Options › Staff (PIN) › Staff tools. Home button › LG HOME makes Home open LG's home screen again. Open when TV turns on › OFF stops Round2 opening at power-on. Both stay until you change them back.
  4. Turn Home back to normal for good: open LG Input Hook from LG's apps row and delete the keybind with ID 773, then Save changes.
  5. Last resort: unplug the TV for 30 seconds. Round2 opens again at start-up, and 3 presses of Home still get you to LG's home screen.

LG TVs that aren't rooted

Nothing to get past: Home always opens LG's own home bar. Round2 Home is opened from its tile in the apps row, and Back returns to it from other apps.

Still stuck?

On an Android TV, run .\round2tv.ps1 diag on the PC straight away. It changes nothing on the TV and saves a file of logs you can send to Claude. On a rooted LG, note what you pressed and what the screen showed.
